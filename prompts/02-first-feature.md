# Codex App: первая сквозная задача

Реализуй endpoint `GET /api/system/info` **только после проверки, существует ли backend-проект**.
Если backend пока нет, сначала предложи минимальный план создания ASP.NET Core проекта и получи моё подтверждение перед созданием существенного каркаса приложения.

Endpoint должен безопасно возвращать JSON с названием приложения, версией и текущим временем UTC. Не раскрывай секреты, строку подключения и детали инфраструктуры.

Используй реальный цикл: `architect` → `developer` → параллельно `test-engineer` и `reviewer` → исправления `developer` при необходимости → повторные проверки.

Запрещены ORM и micro-ORM. Не выполняй деплой и операции с базой данных: для этого endpoint они не нужны.

В итоговом отчёте на русском покажи реально запущенные потоки агентов, изменённые файлы, команды и результаты сборки/тестов, замечания Reviewer и оставшиеся риски.


Дополнительно: после завершения реализации, тестирования и ревью запусти `documentation` для актуализации README и подходящих документов в `docs/` по фактическому API. Требуй отдельный отчёт, что именно было задокументировано. Не запускай `documentation` до стабилизации контракта.
