# Локальная разработка

Порядок запуска API, сборки и проверки приведён в [README](../README.md#проверка). Решение содержит один проект приложения. Проверки API выполняются [Postman-коллекцией](../SocialNetwork.postman_collection.json).

Коллекция содержит девять запросов. Проверяются регистрация, вход, чтение публичной и собственной анкет, а также ошибки ввода и доступа. Для изолированной проверки требуется отдельная база PostgreSQL 17 с [начальной схемой](database.md). База `app_tests` автоматически не создаётся. API запускается с `ConnectionStrings__Postgres`, указывающей на тестовую базу. Переменная `base_url` коллекции должна содержать адрес этого экземпляра API.
