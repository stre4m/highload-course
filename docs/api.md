# REST API

API основан на [спецификации OTUS](https://github.com/OtusTeam/highload/blob/master/homework/openapi.json). Регистрация требует поле `gender`. Маршрут `/user/me` возвращает анкету владельца токена.

| Метод и путь | Запрос | Ответ 200 | Ошибки запроса |
| --- | --- | --- | --- |
| `POST /user/register` | JSON с полями анкеты и `password` | `{"user_id":"<UUID>"}` | `400` — некорректные данные |
| `POST /login` | JSON `{"id":"<UUID>","password":"<пароль>"}` | `{"token":"<токен>"}` | `400` — некорректные данные, `404` — неверная пара UUID и пароля |
| `GET /user/search` | Query-параметры `first_name` и `last_name`, публичный доступ | Массив анкет | `400` — некорректные данные |
| `GET /user/get/{id}` | UUID в пути, публичный доступ | Анкета | `400` — некорректный UUID, `404` — анкета отсутствует |
| `GET /user/me` | Заголовок `Authorization: Bearer <токен>` | Анкета владельца токена | `401` — требуется действительный токен, `404` — анкета отсутствует |

## Поиск анкет

`GET /user/search?first_name=Конст&last_name=Оси` применяет оба префикса. Параметры обязательны. Удаляются начальные и конечные пробелы. Каждый префикс должен иметь длину от 1 до 100 символов и не содержать NUL. Поиск регистрозависимый. Символы `%`, `_` и `!` обрабатываются буквально.

Ответ содержит массив с полями `id`, `first_name`, `second_name`, `birthdate`, `biography` и `city`. Порядок определяется возрастанием UUID. При отсутствии совпадений возвращается `200` с пустым массивом.

## Регистрация

Тело запроса регистрации.

```json
{
  "first_name": "Анна",
  "second_name": "Иванова",
  "birthdate": "1995-04-12",
  "gender": "female",
  "biography": "Книги и путешествия",
  "city": "Алматы",
  "password": "Homework-demo-2026!"
}
```

Все поля обязательны. Дата имеет формат `YYYY-MM-DD` и ограничена текущей датой UTC включительно. У текстовых полей анкеты удаляются начальные и конечные пробельные символы. Результат должен быть непустым и не содержать NUL. Максимальная длина имени, фамилии и города — 100 символов, пола — 50, интересов (`biography`) — 2000.

Пароль для регистрации и входа содержит от 8 до 128 символов. Пароль из одних пробельных символов отклоняется. Нулевой UUID и значения некорректного формата в `POST /login` и `GET /user/get/{id}` возвращают `400`.

Анкета в ответах `/user/get/{id}` и `/user/me` содержит поля `id`, `first_name`, `second_name`, `birthdate`, `gender`, `biography` и `city`. Непрозрачный bearer-токен ASP.NET Core действует один час. Примеры и проверки входят в [Postman-коллекцию](../SocialNetwork.postman_collection.json).
