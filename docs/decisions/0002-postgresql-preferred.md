# ADR-0002: PostgreSQL — предпочтительная СУБД

- **Статус:** принято
- **Дата:** 2026-11-24

## Контекст

Приложению требуется основная СУБД, доступная в локальном окружении Podman.

## Решение

- Использовать PostgreSQL 17. Локальный сервис Podman Compose — `postgres`.
- В .NET использовать `Npgsql` напрямую через ADO.NET, без ORM и micro-ORM.
- Выбирать SQL Server только при явном функциональном или интеграционном требовании. Compose предоставляет SQL Server 2022 в отдельном профиле `sqlserver`. Доступ к данным приложения реализован для PostgreSQL.

## Последствия

- SQL, типы данных, индексы и ограничения проектируются под PostgreSQL.
- Интеграционные проверки выполняются с выбранной СУБД.
- Переход на SQL Server потребует оценки совместимости SQL и типов данных и реализации доступа через другой провайдер.
