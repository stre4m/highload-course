# ADR-0001: Доступ к данным без ORM

- **Статус:** принято
- **Дата:** 2026-11-24

## Контекст

Приложение использует ASP.NET Core и PostgreSQL. Доступ к данным должен осуществляться без ORM и micro-ORM, включая EF Core, EF6, Dapper и NHibernate.

## Решение

Использовать ADO.NET с `Npgsql` для PostgreSQL. При явном требовании использовать SQL Server применять `Microsoft.Data.SqlClient`. Использовать параметризованные запросы, явное преобразование `DbDataReader` в DTO, асинхронные операции и корректное освобождение соединений. Для нескольких команд, требующих совместной атомарности, использовать явную транзакцию. Версионировать SQL-изменения без ORM-миграций.

## Следствия

Обработка `NULL`, преобразование типов и границы транзакций определяются в коде доступа к данным.

## Границы

Доступ к таблице `users` реализован в `UserStore` через `Npgsql`. Регистрация выполняет один атомарный `INSERT`.
