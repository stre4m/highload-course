# ADR-0003. Маршрутизация чтения на реплики PostgreSQL

Статус — принято. Дата — 2026-11-26.

## Контекст

Публичный просмотр и поиск анкет допускают задержку применения WAL. Вход и чтение собственной анкеты требуют актуальных результатов сразу после регистрации.

## Решение

`ConnectionStrings__Postgres` задаёт основной пул. Опциональный `ConnectionStrings__PostgresRead` задаёт отдельный пул для `GET /user/get/{id}` и `GET /user/search`. Регистрация, вход и `GET /user/me` используют основной пул.

В лабораторном режиме строка чтения перечисляет две реплики и задаёт `Target Session Attributes=standby` и `Load Balance Hosts=true`. При отсутствии строки чтения все операции используют основной пул.

## Следствия

Новая анкета может появиться в публичном чтении с задержкой. Если строгий пул standby не может открыть соединение, соответствующий запрос завершается ошибкой. Переключение PostgreSQL выполняется отдельно от маршрутизации приложения.
